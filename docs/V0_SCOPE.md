## Locked v0 defaults

### 1. Task taxonomy — 6 families, everyday config only

| # | Family | Examples in v0 | Out of v0 |
|---|--------|---------------|-----------|
| 1 | VLAN & L2 | create VLAN, name it, access port assignment | VTP, private VLANs, MSTP tuning |
| 2 | Trunk & SVI | 802.1Q trunk, allowed VLANs, SVI + IP | LACP advanced, QinQ |
| 3 | Static routing | IPv4 static, default route, floating static | IPv6 (v0.1), PBR |
| 4 | OSPF | single-area, network statements / interface mode, passive-interface | multi-area, redistribution, auth |
| 5 | BGP basics | eBGP peer, advertise network, basic policy | iBGP RR, communities, route-maps complex |
| 6 | Interface & mgmt basics | description, IP, no shut, SSH/vty basics (scrubbed) | AAA/TACACS full, SNMPv3 |

Target: ~800-900 pairs per family → ~5,000 total.

### 2. Dataset

- **Sources:** (a) mined examples from Cisco IOS XE config guides (recipe: arXiv 2512.02861), (b) synthetic generated by a stronger model + validator, (c) ~100 hand-written seed examples we write first to define the format.
- **Format:** JSONL, see `docs/DATASET_SCHEMA.md`
- **Scrubbing:** strip type-7 / secret hashes, SNMP strings, public IPs (replace with RFC1918 / documentation ranges), hostnames → `sw1`, `r1` etc.
- **Split:** 90 / 5 / 5 train / val / test, stratified by family. Test is held-out, never trained on.

### 3. Validation ladder

1. ciscoconfparse2 — syntax parse
2. Batfish — semantic checks per family (custom questions in `src/validate/`)
3. Emulation — containerlab for v0 spot checks, required gate in v1

### 4. Model & training

- **Base:** Qwen3-4B-Base (Apache 2.0) first. Then same data on Qwen3-1.7B-Base and Qwen3-0.6B-Base to find the floor.
- **Method:** QLoRA, Unsloth (fast path) with TRL SFTTrainer config kept as reference.
- **Budget:** ~10k examples × 3 epochs ≈ 2-4h on RTX 4090 ≈ $2-3 on RunPod. Local fallback: mlx-lm on Mac (~8-10h).
- **Hardware testing:** SKIPPED in v0 (simulator/emulation only). Revisit after v0 evals — you reopened this on Nov 8, so flagging it explicitly.

### 5. Evals before anyone calls it "done"

- Held-out validity rate per family: parse % / Batfish pass % / exact-intent match
- Baseline comparison: base Qwen3-4B (no fine-tune) vs fine-tuned, same prompts
- lm-evaluation-harness sanity check (don't lobotomise general ability)

### 6. Publish

HF Hub (safetensors + GGUF) + dataset repo + this GitHub repo. No publish until evals pass a bar we set after first run.
